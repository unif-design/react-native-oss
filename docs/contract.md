# 行为与所有权

本库从现有客户端的已测试 OSS 实现提取，不改变签名、默认 MIME、30 秒凭证余量、进度间隔、回执、错误文案、取消时序或文件清理归属。

| 原归属 | 公共库处理 | 宿主责任 |
| --- | --- | --- |
| 固定 key 范围 | `createOssCredentialAccess` 接收白名单 | 显式传回原范围，不能因字符串类型扩大权限 |
| 转存子目录 | `getTransferDirectory` | 原平台根目录与原子目录名，保留清理边界 |
| 应用 UUID 工具 | `createId` | 原唯一标识生成器及错误语义 |
| 应用文件能力 | Files 公共入口 | 同版本原生 SDK；补丁由 Portal 维护并在宿主应用 |
| 应用日志入口 | Logger 公共入口 | 统一初始化、策略、身份、格式和存储路径 |
| 企业 STS 与账号 | 不进入本包 | 继续持有 HTTP、认证与 access 失效职责 |

提取时的源码调整限于目录、公共出口、类型声明和构建；SDK 请求内部类型单独存放，避免公共声明要求消费者检查 SDK 的内部 JS 声明。`provided` 凭证不进入 `managed` 缓存。

单文件上传、远程转存和批量各项使用相同的 `urlMode` 语义：默认采用有效 `baseUrl`，`origin` 返回 OSS 原始地址；上传目标、对象路径和文件所有权保持不变。

调用方拥有本地上传源文件，库不删除。取消是尽力终止，不能证明原生读取停止；宿主收到 `onSourceReleased` 才能释放借用文件。回调异常记录安全诊断，不改写回执。

远程转存只拥有本次私有临时文件。下载失败不重复删除；交给上传后由原生终态通知触发清理。身份切换使旧 access 失效，迟到结果不能进入新缓存；本地 dispose 不撤销服务端 STS。
